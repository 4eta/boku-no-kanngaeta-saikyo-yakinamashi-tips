# sa-improve

Simulated Annealing improvement skill for AI coding agent.

## Install

```sh
npx skills add 4eta/boku-no-kanngaeta-saikyo-yakiinamashi-tips
```

## How to use

Ask your AI coding agent with prompts like these:

- `Could you please improve my simulated annealing?`
- `焼きなまし法を改善して`
- `SAの改善案を出して`
- `近傍を改善して`
- `状態の持ち方を変更して`
